## 3. 测试目标、范围与边界

## 7. 上一轮缺陷复测

### 7.1 DEF-REAL-AI04-003：审核接口缺少幂等结果重放

| 项目 | 内容 |
| --- | --- |
| 原优先级 | P2 |
| 本轮状态 | **Closed** |
| 关闭证据 | 持久化键与请求哈希、同请求重放、异请求 409、同店铺跨事件冲突、跨店铺键隔离、单审计均通过 |
| 对应迁移 | `023_marketing_review_idempotency` |

代码与数据库证据：

- `marketing_events` 保存 `ai_review_idempotency_key` 和 `ai_review_request_hash`。
- `(store_id, ai_review_idempotency_key)` 唯一约束阻止同店铺跨事件复用。
- 同键同请求读取首个持久化终态，不重复提交审计。
- 前端在一次业务请求的 401 刷新重试中复用同一个 `stableInit`，不会生成第二个幂等键。
- 审计只保存幂等键 SHA-256、请求摘要和评论摘要，不保存评论原文。

### 7.2 DEF-REAL-AI04-004：并发批准与拒绝可同时成功

| 项目 | 内容 |
| --- | --- |
| 原优先级 | P1 |
| 本轮状态 | **Closed** |
| 关闭证据 | 真实 PostgreSQL 双事务并发中仅一方更新成功，另一方返回 409；数据库只有一个终态和一条成功审计 |

代码与数据库证据：

- Repository 使用带 `waiting_review + pending` 条件的原子 `UPDATE ... RETURNING` 认领审核权。
- 首个事务形成终态后，第二个事务不能再次命中待审条件。
- 审核状态和成功审计位于同一事务；冲突分支回滚，不保留相反成功审计。
- 同键同请求并发时两次调用均可得到同一首个结果，但数据库只保存一条审计。

### 7.3 DEF-REAL-AI04-001/002 与依赖门禁

- AI 营销安全候选进入 `waiting_review + pending`，审核与发送分离，`DEF-REAL-AI04-002` 保持 Closed。

## 9. 代码与安全审查结论

### 9.1 审核幂等和并发

- 023 迁移可升级、回滚和恢复。
- 幂等键成对约束和店铺级唯一约束与 ORM 一致。
- 原子条件更新避免读后写竞争。
- 状态与审计同事务，失败路径不伪装成功。
- 跨店铺访问返回 404，不泄露资源是否存在。

### 9.2 回复、翻译和营销边界

- 审核只记录批准或拒绝，不执行发送或发券。
- AI 营销文案仍是人工审核草稿，不能作为真实触达结果。
- 固定安全评测全部通过，但不能代替新开放集；010 的失败具有更高缺陷判定价值。
- `DEF-P4-AI-009` 未关闭前，合法草稿可能被错误清空，不能把当前实现用于生产客服或营销质量结论。

### 9.3 历史探针兼容说明

002 号报告中的旧内存探针直接替代旧版 `find_event`，而当前实现已改为 Repository 原子 `session.scalar(UPDATE ... RETURNING)`。原脚本重跑得到 3 通过、3 失败、1 跳过，其中 3 个失败均由内存替身缺少 `scalar` 接口造成，不是产品功能失败。本轮已用新的隔离 PostgreSQL 探针替代该失配路径，历史证据文件保持不修改。

## 11. 最终结论

**REAL-AI-04 第三次独立综合测试总体不通过。**

- `DEF-REAL-AI04-003` 已关闭：审核幂等已持久化并实现同请求重放、异请求冲突和店铺级键隔离。
- `DEF-REAL-AI04-004` 已关闭：真实 PostgreSQL 并发批准/拒绝只有一个终态和一条成功审计。
- `DEF-REAL-AI04-001/002` 与 Python 依赖漏洞门禁保持 Closed。
- 本轮没有新增 REAL-AI-04 范围内的 P0/P1/P2/P3 缺陷。
- 但是，用户指定的 010 号问题在当前代码上仍稳定复现：24 条合法内容中 16 条被误杀，`DEF-P4-AI-009` 继续 P2/Reopened。
- `1203` 项隔离 PostgreSQL 全量、`128` 项聚焦、`237` 条固定评测、前端、迁移、静态质量、依赖审计、Compose 和健康检查通过，不能覆盖开放集失败。

因此可确认“营销审核幂等与并发修复”通过，但不能确认 REAL-AI-04 总体或任何生产 AI 能力通过。AIAgent开发工程师Agent完成结构化安全矩阵修复后，必须由测试工程师使用未进入开发固定集的新合法/危险对称样本再次独立复测。
