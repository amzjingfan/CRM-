## 7. 失败项与缺陷

### DEF-P3-013：模型服务依赖存在 9 个已知安全漏洞

| 项目 | 内容 |
| --- | --- |
| 优先级 | **P1** |
| 状态 | 未关闭 |
| 影响范围 | `retrieval-model-service` 镜像、离线模型加载与推理运行环境、发布安全门禁 |
| 责任 Agent | AIAgent开发工程师Agent；架构师Agent协作 |

复现步骤：

1. 进入 `CRM智能聊天系统/backend`。
2. 在允许访问 OSV 的网络环境执行 `uv audit`。
3. 审计返回退出码 1，并报告 `torch 2.10.0` 2 项、`transformers 4.57.6` 7 项漏洞。

关键事实：

- 当前 `pyproject.toml` 将版本限制为 `torch>=2.10,<2.11`、`transformers>=4.57,<4.58`。
- 部分公告的修复版本已超出当前兼容范围，另有公告暂未给出修复版本。
- `Dockerfile.model-service` 使用 `uv sync --extra retrieval-model` 安装这些依赖，不能仅以“可选依赖”排除风险。

期望结果：由 AI Agent 工程师和架构师完成可兼容升级评估；无修复版本的条目必须形成书面风险接受和补偿控制，至少限制模型来源、保持只读模型挂载、隔离网络与权限，并把安全审计纳入发布门禁。在完成处置前不建议发布 AI profile。

### DEF-P3-014：知识库和营销数据行在移动端/平板产生横向溢出

| 项目 | 内容 |
| --- | --- |
| 优先级 | **P2** |
| 状态 | 未关闭 |
| 影响范围 | 知识库 FAQ 操作、营销活动操作、375px 移动端与 1024px 平板布局 |
| 责任 Agent | 全栈开发工程师Agent |

复现步骤：

1. 登录管理端并创建至少一条 FAQ、至少一条营销活动。
2. 在 375×900 打开 `/knowledge`，观察 FAQ 行操作按钮和页面横向滚动。
3. 在 375×900、1024×900 打开 `/marketing`，观察活动状态和 Edit/Enable/Delete 操作区。
4. 比较 `document.documentElement.scrollWidth` 与 `clientWidth`。

实际结果：知识库 375px 溢出 92px；营销 375px 溢出 40px、1024px 溢出 51px。空数据状态不出现该问题。

代码线索：`frontend/app/globals.css` 中 `.data-row` 使用横向 flex，`.row-actions` 使用 `flex: 0 0 auto`；移动端规则只改变对齐方式，未允许操作区换行或约束宽度。知识库和营销数据行均复用该结构。

期望结果：数据态页面在 375/768/1024/1440px 均不得出现整体横向滚动；操作按钮应在容器内换行、折叠或改为菜单，同时保持 44px 触控区域和键盘可达性。
