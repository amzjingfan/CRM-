## 6. 阈值校准

原默认 Dense 阈值 `0.45` 的结果为：

- 有答案样本 Recall@5：100%。
- 无答案正确转人工率：17/20，85%，未达到 90% 门禁。

对 `0.30～0.90` 执行步长 `0.01` 的固定网格评测后：

- `0.48～0.51`：有答案 Recall@5 为 100%，拒判率为 95%。
- `0.52～0.56`：两项均为 100%。
- `0.57` 起开始损失有答案召回。

因此选择满足双门禁的最小稳定阈值 `0.52`，并已同步到：

- `backend/app/shared/config/settings.py`
- `.env.example`
- `README.md`
- `AI agent 开发工程师/AI-002-RAG-FAQ检索与Agent工作流规范-v1.4.md`

新增自动化测试锁定默认阈值，先在 `0.45` 下失败，再在 `0.52` 下通过。
