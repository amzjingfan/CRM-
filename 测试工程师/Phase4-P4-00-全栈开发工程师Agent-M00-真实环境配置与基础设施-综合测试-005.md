```powershell
npm audit --registry=https://registry.npmjs.org --audit-level=high --json
```

实际结果：进程退出码 1，`metadata.vulnerabilities.high=3`。

### 6.2 `DEF-REAL-FS01-006`：关键日志事件语义折叠

| 项目 | 内容 |
| --- | --- |
| 优先级 | P2 |
| 状态 | Open |
| 影响 | 没有稳定结构化 `event` 的第三方或框架日志统一折叠，生产告警、检索和根因定位无法区分关键事件 |
| 当前实现 | `JsonFormatter` 只接受 `SAFE_EVENT_PATTERN`；缺失或不匹配时写入 `unstructured_log_redacted` |
| 安全说明 | 当前行为保护客户正文和凭证，修复不得放宽自由文本进入日志；应为允许的关键框架事件建立低敏结构化映射 |

复验运行探针输出：

```json
{"event":"unstructured_log_redacted","message":"unstructured_log_redacted"}
```

后续多份权威报告仍将该缺陷列为 Open，没有可用于关闭它的独立复测证据。
