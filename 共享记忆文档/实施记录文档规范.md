# CRM 智能聊天系统实施记录文档规范

## 1. 目的

实施记录用于回答以下问题：

- 本次工作属于哪个 Phase、哪个任务？
- 由哪个 Agent 主责，哪些 Agent 协作？
- 依据哪些需求、接口、架构和验收标准实施？
- 修改了什么，如何验证，仍有哪些风险？

所有架构设计、产品代码、AI 能力、开发工具和重大配置变更完成后，都必须生成实施记录。

测试工程师执行测试时生成测试报告，不使用实施记录替代测试报告。测试报告和测试结论的权威文件统一存放在 `测试工程师/`。

测试报告命名必须遵守 `测试工程师/测试报告命名规范.md`：大范围测试保留原格式，阶段性测试必须在文件名中明确 Phase、任务编号和被测主责 Agent。

## 2. 存放位置

实施记录统一存放在：

```text
共享记忆文档/实施记录/
```

不得把实施记录放入正式代码目录。历史实施记录可以保留原位置；新记录必须使用上述目录和本规范。

## 3. 文件命名格式

```text
Phase{阶段号}-{任务编号}-{主责Agent}-{实施主题}-{三位序号}.md
```

字段要求：

| 字段 | 规则 | 示例 |
| --- | --- | --- |
| Phase阶段号 | 使用 `Phase1`、`Phase2`、`Phase3`、`Phase4`；跨阶段工作使用 `PhaseX` | `Phase2` |
| 任务编号 | 单任务使用任务拆解中的编号；阶段汇总使用 `P{阶段号}-00`；无正式编号时使用 `PX-00` 并标记待补充 | `P2-07` |
| 主责Agent | 必须使用下方固定名称 | `AIAgent开发工程师Agent` |
| 实施主题 | 10～30 个中文字符，准确描述交付内容 | `Agent对话编排` |
| 三位序号 | 同一 Phase、任务和 Agent 从 `001` 递增 | `001` |

固定 Agent 名称：

- `架构师Agent`
- `AIAgent开发工程师Agent`
- `全栈开发工程师Agent`
- `测试工程师Agent`
- `开发工具Agent`
- `共享记忆文档Agent`

命名示例：

```text
Phase1-P1-03-全栈开发工程师Agent-FastAPI工程骨架-001.md
Phase1-P1-00-全栈开发工程师Agent-工程地基与认证阶段汇总-001.md
Phase2-P2-07-AIAgent开发工程师Agent-Agent对话编排-001.md
Phase2-P2-09-全栈开发工程师Agent-SSE流式输出-001.md
PhaseX-PX-00-架构师Agent-跨阶段架构治理-001.md
```

## 4. 状态值

实施状态只能使用：

- `计划中`
- `实施中`
- `已完成`
- `部分完成`
- `已阻塞`
- `已取消`

`已完成` 必须有实际验证证据；仅完成编码但未验证时只能标记为 `部分完成`。

## 5. 文档模板

每份实施记录必须使用以下结构，不适用的项目填写“不适用”并说明原因，不得直接删除章节。

```markdown
# {实施主题}实施记录

## 1. 基本信息

| 项目 | 内容 |
| --- | --- |
| Phase | Phase{阶段号} |
| 任务编号 | {P1-01 / P2-07 / P1-00阶段汇总 / PX-00} |
| 模块编号 | {M01 / M02 / 待确认} |
| 主责 Agent | {固定 Agent 名称} |
| 协作 Agent | {固定 Agent 名称；无则填写“无”} |

| 完成日期 | {YYYY-MM-DD / 未完成} |
| 代码位置 | `CRM智能聊天系统/` 或“不涉及代码” |
```

## 6. Agent 责任规则

- 主责 Agent 负责创建和维护实施记录。
- 主责 Agent 创建记录后必须更新 `共享记忆文档/实施记录索引.md`。
- 协作 Agent 只补充自己负责部分，不能替主责 Agent 改写最终状态。
- 架构师负责检查 Phase、任务边界、依赖和技术决策是否准确。
- 测试工程师依据实施记录制定测试范围，但测试报告另行存放在 `测试工程师/`。
- 共享记忆文档 Agent 负责文件命名、索引和版本一致性检查。

## 7. 测试产物边界

以下文件必须存放在 `测试工程师/`：

- 测试计划。
- 测试用例。
- 缺陷记录。
- 测试报告。
- 回归报告。
- 性能报告。
- AI 评测报告。
- 正式测试结论和是否建议验收的结论。

`共享记忆文档/` 只保存：

- `测试报告索引.md`。
- 项目级 Phase 状态和发布/验收状态。
- 指向测试工程师权威报告的相对路径。

共享记忆文档不得复制完整测试报告或创建第二份相互竞争的测试结论。
