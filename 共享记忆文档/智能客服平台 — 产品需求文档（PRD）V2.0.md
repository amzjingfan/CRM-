# AI Agent 智能客服平台 — 产品需求文档（PRD）V2.0

**版本**：V2.0（从0开始·务实版）
**状态**：待评审
**日期**：2026-01-15
**密级**：内部机密

------

## 1. 项目背景

团队计划从0开始打造一套面向跨境电商的智能客服系统，解决以下核心痛点：

| 痛点             | 说明                                           |
| :--------------- | :--------------------------------------------- |
| 多平台消息分散   | TikTok/Shopee/Amazon后台切换频繁，无法统一管理 |
| 重复咨询消耗人力 | 物流、尺码、退换货等高频问题占用客服80%时间    |
| 无主动营销能力   | 无法识别弃单、差评等商机并自动触达             |
| 数据分散无分析   | 各平台数据割裂，缺乏统一决策依据               |

**核心原则**：先跑通核心闭环，再逐步扩展。

------

## 2. 产品目标（MVP）

> 发布范围说明（2026-09-08）：本节与后续功能范围继续定义“三平台完整 MVP”。首个真实发布版本 v0.1 采用 TikTok 人工辅助限定生产发布，只验收 TikTok OAuth、读取、Webhook、人工发送、AI 建议、RAG、工作台、知识库和看板；它不是完整 MVP 完成声明。范围、门禁和非目标以 `架构师/ADR-006-CROSS-TikTok人工辅助首版发布范围-v1.0.md` 为准，Shopee/Amazon、自动回复和主动触达继续保留为后续实现目标。

| 目标         | 量化指标                                       |
| :----------- | :--------------------------------------------- |
| AI独立解决率 | ≥70%常见咨询（物流/退换货/尺码/价格/活动5类）  |
| 响应速度     | AI首字延迟 < 3秒                               |
| 平台接入     | 至少3个主流平台（TikTok Shop、Shopee、Amazon） |
| 主动挽回     | 弃单挽回成功率 ≥5%                             |
| 系统可用性   | ≥99.5%                                         |

------

## 3. MVP功能范围（精简版）

### 3.1 必须包含（P0）

| 模块           | 核心功能                                     | 说明                   |
| :------------- | :------------------------------------------- | :--------------------- |
| **客服工作台** | 会话列表、聊天窗口、客户侧边栏、快捷回复     | 客服处理会话的唯一入口 |
| **AI智能问答** | 意图识别（5类）、RAG知识库问答、置信度转人工 | 核心AI能力             |
| **知识库**     | FAQ增删改查、分类管理                        | AI的知识来源           |
| **主动触达**   | 弃单挽回（自动发券）、中差评跟进（自动道歉） | 核心营销能力           |
| **数据看板**   | 会话量、转人工率、平均响应、挽回GMV          | 4个核心指标卡          |
| **系统配置**   | 店铺接入、员工管理                           | 基础运维               |

### 3.2 不包含（推迟到V1.1+）

- WhatsApp低成本接入（技术风险高，先用官方API）
- 亚马逊创作者计划（需求不明确）
- 多渠道获客（非核心）
- 多Agent协同（先用单Agent模式）
- A2A分布式协议（先用单体FastAPI）

## 4. 核心功能需求

### 4.1 客服工作台

**页面结构**：三栏布局（会话列表 | 聊天窗口 | 智能辅助）

**功能清单**：

| 功能       | 说明                                    |
| :--------- | :-------------------------------------- |
| 会话列表   | 展示所有会话，支持按平台/店铺/未读筛选  |
| 聊天窗口   | 展示对话历史，支持文本输入和发送        |
| 客户侧边栏 | 展示客户画像（姓名/标签/订单数/客单价） |
| AI建议回复 | 自动生成回复建议，一键使用              |
| 快捷操作   | 查订单、改地址、发优惠券、转人工        |
| 消息状态   | 已读/未读/已发送/已送达                 |

------

### 4.2 AI智能问答

**核心流程**：

text

```
用户消息 → 意图识别 → RAG检索 → LLM生成 → 置信度判断 → 回复/转人工
```



**意图分类（MVP 5类）**：

| 意图            | 说明         | 示例                 |
| :-------------- | :----------- | :------------------- |
| logistics_query | 物流查询     | "我的订单到哪了？"   |
| return_policy   | 退换货咨询   | "怎么退货？"         |
| size_guide      | 尺码咨询     | "这个衣服M码多大？"  |
| price_inquiry   | 价格咨询     | "这个多少钱？"       |
| general         | 其他通用问题 | "你们客服电话多少？" |

**置信度规则**：

| 置信度  | 动作                  |
| :------ | :-------------------- |
| ≥80%    | AI直接回复            |
| 60%-80% | AI回复 + 人工复核标记 |
| <60%    | 建议转人工            |

------

### 4.3 知识库

**四层结构（简化版）**：

| 层级 | 说明     | 示例                     |
| :--- | :------- | :----------------------- |
| A层  | 原始数据 | 商品详情页、物流政策文档 |
| B层  | 业务规则 | 运费计算规则、退货期限   |
| C层  | 问答对   | FAQ（问题-答案）         |
| D层  | 案例库   | 历史典型对话案例         |

**MVP实现**：先做C层（FAQ问答对），A/B/D层后续扩展。

------

### 4.4 主动触达

| 场景       | 触发条件       | 动作              | 时效   |
| :--------- | :------------- | :---------------- | :----- |
| 弃单挽回   | 用户加购未付款 | 自动发送优惠券    | ≤5分钟 |
| 中差评跟进 | 平台出现中差评 | 自动发送道歉+补偿 | ≤5分钟 |
| 物流关怀   | 订单发货/签收  | 自动推送物流状态  | 实时   |

------

### 4.5 数据看板

| 指标     | 说明                       |
| :------- | :------------------------- |
| 会话量   | 今日/本周/本月总会话数     |
| 转人工率 | AI转人工的比例             |
| 平均响应 | 客服平均响应时间           |
| 挽回GMV  | 通过主动触达挽回的订单金额 |
| 趋势图   | 近7天会话量变化            |
| 渠道分布 | 各平台会话占比             |

## 5. 技术架构（MVP）

| 层级     | 技术选型                | 说明                 |
| :------- | :---------------------- | :------------------- |
| 后端     | Python FastAPI          | 全栈统一，快速迭代   |
| 前端     | Next.js + Tailwind CSS  | 管理后台UI           |
| 数据库   | PostgreSQL + pgvector   | 业务数据 + 向量检索  |
| 缓存     | Redis                   | 会话缓存、频控       |
| LLM      | Claude API / OpenAI API | 按用量计费           |
| 部署     | Docker Compose → K8s    | 先单体后微服务       |
| 平台接入 | 各平台官方API           | TikTok/Shopee/Amazon |
