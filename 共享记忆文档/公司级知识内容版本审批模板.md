# 公司级知识内容版本审批模板

> 本模板是治理记录，不是 RAG 语料。复制使用时必须为单一、确定字节的公司自编内容建立一份审批记录；禁止在本文件填入 Token、店铺 ID、客户数据或官方原文。

## 1. 版本身份与来源

| 字段 | 填写值 |
| --- | --- |
| content_version_id | 待填写；全局唯一且不可复用 |
| title | 待填写 |
| content_sha256 | 待生成；必须对应实际批准字节，不得对 URL 或临时草稿计算 |
| source_id | 待填写 |
| coverage_cell_id | 待填写 |
| source_reviewed_at | 待填写 |
| source_displayed_updated_at | 待填写；来源未显示时写“未提供”，不得猜测 |
| rights_basis_ref | 待填写 |
| rights_review_status / reviewed_at | 待填写 |
| statement_type | `policy_rule / operation_guide / product_fact / approved_faq / approved_case` 之一 |
| risk_level | `低 / 中 / 高` |

## 2. 适用与授权边界

| 字段 | 填写值 |
| --- | --- |
| platform / market / language | 待填写 |
| audience | 待填写 |
| space_code | `company_shared / shop_private` |
| shop_ref | `company_shared` 必须为空；`shop_private` 必填稳定低敏代号 |
| allowed_app_refs | 待填写；仅登记获准内部消费系统 |
| effective_from / effective_until | 待填写 |
| condition_variables | 待填写 |
| no_answer_boundaries | 待填写 |
| automatic_delivery_allowed | `false`；如未来变更必须走单独架构与产品审批 |
| forbidden_uses | 待填写 |

## 3. 内容与冲突控制

| 字段 | 填写值 |
| --- | --- |
| content_owner_ref | 待填写 |
| supersedes_version_id | 无 / 待填写 |
| conflicting_version_ids | 无 / 待填写 |
| conflict_decision_ref | 无 / 待填写；存在冲突时必须人工裁定 |
| review_due_at | 待填写 |
| revocation_trigger | 来源撤销、权利到期、政策变化、错误确认、店铺/应用授权失效等 |
| index_state | `not_indexed`；审批完成前不得修改为可服务状态 |
| rollback_target | 待填写；无安全旧版本时使用 `no_evidence` |

## 4. 审批记录

| 角色 | 审核范围 | 决定 | 审核人 | 日期 | 证据/意见 |
| --- | --- | --- | --- | --- | --- |
| 内容负责人 | 公司自编陈述的业务准确性、条件和时效 | 接受 / 修改后接受 / 拒绝 / 延期 | 待填写 | 待填写 | 待填写 |
| 来源权利负责人 | 许可、保存、向量化、内部引用和撤销边界 | 接受 / 修改后接受 / 拒绝 / 延期 | 待填写 | 待填写 | 待填写 |
| 专业/合规复核 | 高风险领域的专业准确性 | 接受 / 修改后接受 / 拒绝 / 延期 / 不适用 | 待填写 | 待填写 | 待填写 |
| 架构师Agent | 空间、身份、数据所有权、版本和失败关闭 | 接受 / 修改后接受 / 拒绝 / 延期 | 待填写 | 待填写 | 待填写 |
| 测试工程师Agent | 冻结集、越权、过期、冲突、引用和拒答结果 | 通过 / 有条件通过 / 不通过 / 阻塞 | 待填写 | 待填写 | 正式报告路径待填写 |

## 5. 最终发布决定

| 字段 | 填写值 |
| --- | --- |
| approval_ref | 待填写 |
| final_decision | `approved / rejected / deferred / revoked` |
| approved_by / approved_at | 待填写；`approved` 时必填 |
| publish_prerequisites | K3 导入任务、索引版本、目标环境和回滚验证 |
| revocation_completed_at | 不适用 / 待填写 |

只有全部必填项完整、权利未过期、内容哈希与批准字节一致、冲突已裁定且独立测试通过时，`final_decision` 才能写 `approved`。任何角色未回复均视为未签署；索引成功、检索命中或页面可访问都不能替代审批。
