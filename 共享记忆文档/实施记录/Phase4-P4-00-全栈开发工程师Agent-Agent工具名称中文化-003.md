## 5. 实施方案

### 5.1 方案说明

在 Agent 页面定义工具代码到中英文名称的静态映射。复选框的 `name` 继续使用工具代码，界面文本按当前语言显示可读名称，避免展示层本地化影响后端契约。

### 5.2 依赖关系

- 前置依赖：现有 Agent 工具白名单和前端语言状态。
- 后续依赖：测试工程师可在 Agent 页面回归中文、英文显示和保存行为。

### 5.3 风险控制

| 风险 | 影响 | 应对措施 |
| --- | --- | --- |
| 中文名称替换工具代码 | 保存配置时工具字段失效 | 仅替换文本节点，复选框 `name` 保留原工具代码 |
| 新增工具遗漏名称 | 页面出现空白或类型错误 | 映射类型绑定工具数组元素，并通过 TypeScript 检查 |
