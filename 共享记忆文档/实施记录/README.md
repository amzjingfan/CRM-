# 实施记录目录

本目录统一存放项目实施记录。

创建记录前必须阅读：

- `共享记忆文档/实施记录文档规范.md`
- `共享记忆文档/项目团队职责说明.md`
- 与任务相关的 PRD、接口、任务拆解和验收标准
- 涉及代码时阅读 `共享记忆文档/代码编写手册.md`

文件名必须使用：

```text
Phase{阶段号}-{任务编号}-{主责Agent}-{实施主题}-{三位序号}.md
```

历史文件 `Phase1工程地基与认证实施记录-v1.0.md` 和 `Phase2平台接入会话与工作台实施记录-v1.0.md` 已于 2026-08-20 迁移到本目录，并补齐 Phase、任务编号、主责/协作 Agent、需求依据、验证、风险和交接信息。后续新增或修订记录必须继续使用新格式。
