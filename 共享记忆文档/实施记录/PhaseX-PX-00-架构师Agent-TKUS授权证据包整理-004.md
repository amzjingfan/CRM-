## 5. 实施方案

### 5.1 方案说明

在用户已登录的两个平台页面进行只读核验，仅提取应用名称、市场、状态、相关 Scope 和回调一致性。敏感字段从证据中剔除，并将应用级权限、令牌级授权、CRM 绑定和数据使用权分层判定。

### 5.2 依赖关系

- 前置依赖：用户完成 Seller Center 与 Partner Center 登录并指定 `tkw api`。
- 后续依赖：受控 CRM 运行环境、稳定 `shop_ref`、产品签认、独立测试及平台协议/隐私审批。

### 5.3 风险控制

| 风险 | 影响 | 应对措施 |
| --- | --- | --- |
| 页面展示凭据和内部标识 | 敏感数据进入 Git | 只登记低敏结论，禁止应用 ID、密钥、Token 和真实店铺 ID |
| 应用级权限被误认为令牌授权 | 错误放行真实 API | 明确令牌 `granted_scopes` 与只读调用仍待测 |
| 平台授权被误认为 RAG 使用许可 | 私有数据越权共享 | 保持 `shop_private` 与知识摄取门禁关闭 |
