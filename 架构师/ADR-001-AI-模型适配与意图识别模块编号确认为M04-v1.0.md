# 架构决策记录：模型适配与意图识别模块编号确认为 M04

| 项目 | 内容 |
| :--- | :--- |
| 决策编号 | `ADR-001-AI` |
| 版本 | `v1.0` |
| 状态 | 已确认 |
| 决策日期 | 2026-08-20 |
| 决策 Agent | 架构师 Agent |
| 影响范围 | Phase1 / P2-01、P2-02 / AI 测试与实施记录 |

## 1. 背景

测试工程师发现以下编号不一致：

- 初始 AI 评测报告文件名使用 `M02`。
- 最新 AI 复测报告文件名使用 `M01`。
- AI 实施记录正文使用 `M01`。
- 架构文档此前未正式确认 AI 模块编号。

## 2. 既有模块编号核对

根据现有实施记录和测试报告索引，项目模块编号已经形成以下占用关系：

| 模块编号 | 正式模块名称 | 依据 |
| :--- | :--- | :--- |
| `M01` | 工程地基与认证 | Phase1-P1-00 实施记录及 M01 综合测试报告 |
| `M02` | 平台接入、会话与客服工作台 | Phase2-P2-00 实施记录 |
| `M03` | 知识库、业务工具与主动营销 | Phase3-P3-00 实施记录 |
| `M04` | 模型适配与意图识别 | 本决策记录 |

## 3. 正式决策

架构师正式确认：

```text
M04 = 模型适配与意图识别
```

该模块覆盖：

- OpenAI/Claude 模型适配。
- 结构化输出、错误分类和截断响应处理。
- 五类 MVP 意图识别。
- 拒判、置信度和人工接管动作。
- `agent_runs` 运行追踪。
- AI 离线评测、真实模型评测门禁和安全回归。

任务归属保持不变：`Phase1 / P2-01`，关联 `P2-02`；主责 Agent 为 `AIAgent开发工程师Agent`。

## 4. 历史文件处理规则

两份已有测试报告是历史测试证据，不删除、不覆盖、不强制改名：

- `测试工程师/Phase1-P2-01-AIAgent开发工程师Agent-M02-模型适配与意图识别-AI评测-001.md`
- `测试工程师/Phase1-P2-01-AIAgent开发工程师Agent-M01-模型适配与意图识别-AI评测-002.md`

它们的正文仍保留当时的临时编号说明；在测试报告索引和后续文档中统一以 `M04` 作为正式模块编号，并注明历史文件名。

后续测试报告必须使用：

```text
Phase1-P2-01-AIAgent开发工程师Agent-M04-模型适配与意图识别-AI评测-003.md
```

后续实施记录的“模块编号”必须填写 `M04`。

## 5. 影响与后续动作

- 测试工程师：后续复测报告使用 `M04`，序号从 `003` 继续，不覆盖历史报告。
- 共享记忆文档 Agent：更新测试报告索引和实施记录索引关联说明。
- AI Agent 开发工程师：在实施记录和交接文档中使用 `M04`。
- 架构师：后续架构、验收和风险文档使用 `M04-模型适配与意图识别`。

本决策不改变代码路径、数据库表名、API 路径或运行逻辑，仅统一项目追踪编号。
