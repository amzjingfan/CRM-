## 1. 本次要决定什么

评审 [ADR-001-KB 提案](ADR-001-KB-独立知识服务与空间授权边界-v1.0.md)：是否以独立知识服务和专属数据所有权承载公司共享/店铺私有知识；服务与 CRM/第二系统如何验证应用和店铺授权；新旧 FAQ 如何兼容及回滚；TK 美国站页面和 API 数据的权利门禁如何落实。用户已确认设计方向、首批 US 市场和物流/履约、退换退款、商品信息/规格三个试点场景，并指定架构负责来源治理；`RGT-TK-US-PUBLIC-001` 进一步形成了公开来源的公司内部受限使用审批，但项目级联合技术/安全签署、内容版本发布和 API Data 权利仍未完成。

评审输入：`ARCH-001-KB-公司级跨境电商知识服务设计-v1.0.md`、`ADR-001-KB-独立知识服务与空间授权边界-v1.0.md`、`DATA-001-KB-公司级知识来源与覆盖治理-v1.0.md`、`共享记忆文档/公司级跨境电商知识覆盖矩阵.md`、`共享记忆文档/公司级知识来源登记与许可清单.md`、`AUTH-TK-US-001/002`、`RGT-TK-US-PUBLIC-001`、ADR-005/006、管理端接口第 11.1/11.16 节、现有 CRM 知识表/检索代码。公开 TK-US 来源链接只供权利和适用性核对；受限审批只允许公司自编内容，不代表官方正文可复制为语料。

### 3.1 架构师Agent 本角色技术审阅记录（2026-09-14）

签署范围仅为架构技术意见。结论：`延期`。独立服务、权威数据隔离、失败关闭、逐版本审批和保留旧 FAQ 回滚链路作为后续详细设计的原则方向；证据未补齐前不将 ADR-001-KB 改为 `Accepted`，不开放真实私有知识的 K2 实施或来源正文采集。

| 议题 | 本角色意见 | 尚缺的可核验证据 |
| --- | --- | --- |
| `KB-G0-01` | 原则方向可保留，决议延期 | 现有 CRM 知识表确实外键依赖 `stores/users`；独立数据库/角色、MinIO 权限、备份恢复和容量尚无全栈验证 |
| `KB-G0-02` | 失败关闭边界可保留，决议延期 | 应用身份签发者、受众、撤销/轮换及店铺授权权威尚未固定，跨店/跨系统负测未形成 |
| `KB-G0-03` | 权利未知时禁止准入，决议延期 | `RGT-TK-US-PUBLIC-001` 已允许七条来源元数据和已审批公司自编内容在登记的内部系统受控使用；官方正文、快照、原文向量化、片段展示和 API Data 明确未批准，内容版本、专业复核与独立 QA 仍缺 |
| `KB-G0-04` | 与 ADR-005 逐版本审批方向一致，决议延期 | 新服务状态机及撤销/过期/冲突的实现和独立负测未形成 |
| `KB-G0-05` | 证据 API 不代替答案/平台动作的边界可保留，决议延期 | 内部 DTO、授权错误与 `no_evidence`/`unavailable` 故障映射未定稿 |
| `KB-G0-06` | 旧 FAQ 只迁合格版本并保留回滚的方向可保留，决议延期 | 映射清单、双读差异、延迟与回滚演练尚无证据 |
| `KB-G0-07` | 三类 US 试点范围已由用户选择，决议延期 | 产品规格不能由 `Product Listing Policy` 证明；物流指南也不能单独覆盖所有履约规则；独立样本与质量门槛待产品/AI/测试冻结 |

本角色审阅依据为现有 CRM `knowledge_base/models.py` 的 `stores/users` 外键、ADR-005/006、生产放行检查表 G1、K1 来源登记以及 TikTok US 页面低敏核验；它是技术风险处置意见，不是对其他岗位、平台条款或真实店铺的代签。脱敏店铺证据现状见 `共享记忆文档/TK-US已授权店铺范围核验证据.md`；`AUTH-TK-US-001` 只支持店铺侧授权存在性与应用级 Scope，`AUTH-TK-US-002` 只支持配置对应关系，均不支持真实令牌/CRM 运行态绑定；`RGT-TK-US-PUBLIC-001` 仅批准公开来源的内部受限使用形式，不覆盖官方原文、API Data 或内容版本发布。

评审必须对每项记录 `接受 / 修改后接受 / 拒绝 / 延期`、具体异议、责任人、证据链接和日期；不得将“未回复”视为同意。若独立数据库、身份签发/店铺授权权威或 TK 数据使用权不能确定，ADR 保持评审中，K2 只能做不接真实数据的设计验证，不能放开可访问私有知识的实现或生产开关。

## 4. 验收边界与交接

KB-G0 的出口是正式签署后的 ADR、已固定的内部接口/安全设计任务、任务编号和共享记忆同步；不是代码运行或生产放行。生产 G0～G8 继续按 ADR-006 独立执行。K1 已取得公开来源的内部受限使用审批，但内容负责人逐版本签署、高风险专业复核、冻结样本和测试工程师验收仍未完成，因此仍只能标“部分完成”；八领域有效覆盖当前为 0。
