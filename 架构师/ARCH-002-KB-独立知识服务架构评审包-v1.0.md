## 1. 本次要决定什么

评审输入：`ARCH-001-KB-公司级跨境电商知识服务设计-v1.0.md`、`ADR-001-KB-独立知识服务与空间授权边界-v1.0.md`、`DATA-001-KB-公司级知识来源与覆盖治理-v1.0.md`、`共享记忆文档/公司级跨境电商知识覆盖矩阵.md`、`共享记忆文档/公司级知识来源登记与许可清单.md`、ADR-005/006、管理端接口第 11.1/11.16 节、现有 CRM 知识表/检索代码。公开 TK-US 来源链接只供权利和适用性核对，不代表可复制为语料。

### 3.1 架构师Agent 本角色技术审阅记录（2026-09-14）

签署范围仅为架构技术意见。结论：`延期`。独立服务、权威数据隔离、失败关闭、逐版本审批和保留旧 FAQ 回滚链路作为后续详细设计的原则方向；证据未补齐前不将 ADR-001-KB 改为 `Accepted`，不开放真实私有知识的 K2 实施或来源正文采集。

| 议题 | 本角色意见 | 尚缺的可核验证据 |
| --- | --- | --- |
| `KB-G0-01` | 原则方向可保留，决议延期 | 现有 CRM 知识表确实外键依赖 `stores/users`；独立数据库/角色、MinIO 权限、备份恢复和容量尚无全栈验证 |
| `KB-G0-02` | 失败关闭边界可保留，决议延期 | 应用身份签发者、受众、撤销/轮换及店铺授权权威尚未固定，跨店/跨系统负测未形成 |
| `KB-G0-03` | 权利未知时禁止准入，决议延期 | 七条页面没有逐条保存、向量化、片段展示及跨系统使用权签署；实际卖家/开发者协议适用版本待核 |
| `KB-G0-04` | 与 ADR-005 逐版本审批方向一致，决议延期 | 新服务状态机及撤销/过期/冲突的实现和独立负测未形成 |
| `KB-G0-05` | 证据 API 不代替答案/平台动作的边界可保留，决议延期 | 内部 DTO、授权错误与 `no_evidence`/`unavailable` 故障映射未定稿 |
| `KB-G0-06` | 旧 FAQ 只迁合格版本并保留回滚的方向可保留，决议延期 | 映射清单、双读差异、延迟与回滚演练尚无证据 |
| `KB-G0-07` | 三类 US 试点范围已由用户选择，决议延期 | 产品规格不能由 `Product Listing Policy` 证明；物流指南也不能单独覆盖所有履约规则；独立样本与质量门槛待产品/AI/测试冻结 |

本角色审阅依据为现有 CRM `knowledge_base/models.py` 的 `stores/users` 外键、ADR-005/006、生产放行检查表 G1、K1 来源登记以及 2026-09-14 核对的 TikTok US 官方页面；它是技术风险处置意见，不是对其他岗位、平台条款或真实店铺的代签。脱敏店铺证据现状见 `共享记忆文档/TK-US已授权店铺范围核验证据.md`。

评审必须对每项记录 `接受 / 修改后接受 / 拒绝 / 延期`、具体异议、责任人、证据链接和日期；不得将“未回复”视为同意。若独立数据库、身份签发/店铺授权权威或 TK 数据使用权不能确定，ADR 保持评审中，K2 只能做不接真实数据的设计验证，不能放开可访问私有知识的实现或生产开关。

## 4. 验收边界与交接

KB-G0 的出口是正式签署后的 ADR、已固定的内部接口/安全设计任务、任务编号和共享记忆同步；不是代码运行或生产放行。生产 G0～G8 继续按 ADR-006 独立执行。K1 可并行形成全域目录与候选来源，但没有权利审批、内容负责人、首批场景和测试工程师验收前，只能标“部分完成”；八领域有效覆盖当前为 0。

正式评审通过后，架构师将 ADR 状态更新为 `已确认` 并记录决议及异议处理；全栈与 AI 分别制定 K2/K3 代码级计划，测试工程师在 `测试工程师/` 制定独立计划。若评审修改本提案的核心边界，先修订设计/ADR/覆盖治理，再进入实施，不能以本评审包替代签署。
