## 3. 证据检查项

### G0 基线、安全和恢复

- [ ] 固定代码提交或等效不可变归档哈希。
- [ ] 固定镜像摘要、迁移 head 和环境配置版本。
- [ ] TikTok、DeepSeek、JWT、Cookie、CSRF 和内部 Token 分环境隔离。
- [ ] 凭证不进入前端、日志、数据库明文字段和测试报告。
- [ ] PostgreSQL、Redis、MinIO 备份与恢复演练通过。
- [ ] 单个功能开关回滚和全部真实能力紧急关闭演练通过。

### G1 TikTok OAuth 与只读

- [ ] OAuth `state` 一次性、过期、重复和 CSRF 场景通过。
- [ ] callback 固定为 `https://www.hophorsefit.com/v1/integrations/tiktok/oauth/callback`。
- [ ] Token 交换、刷新、过期识别和撤销通过。
- [ ] 店铺身份、Scope 和内部 `store_id` 绑定通过。
- [ ] 订单、物流和店铺只读查询通过店铺隔离测试。

### G2 Webhook

- [ ] 地址固定为 `https://www.hophorsefit.com/v1/webhooks/tiktok`。
- [ ] 合法签名、非法签名、过期时间戳和超大正文通过。
- [ ] 重复事件、平台重试、Worker 失败和重复消息幂等通过。
- [ ] Webhook 快速响应，不把原始正文写入应用日志。

### G3 普通人工消息

- [ ] 只开放单店铺、单账号、人工确认普通文本。
- [ ] 权限、店铺范围、二次确认和 `Idempotency-Key` 通过。
- [ ] 成功、失败、重复、超时和 `unknown` 状态通过。
- [ ] `tool_calls`、`audit_logs` 和平台请求 ID 可追溯。

### G4 DeepSeek 安全与质量

- [ ] `DEF-P4-AI-008` 由独立变形样本复测关闭。
- [ ] `DEF-P4-AI-009` 由独立合法样本复测关闭。
- [ ] 结构化业务声明绑定对象、动作、时态、极性、条件和证据。
- [ ] 回复、翻译、营销、多语言、工具失败和模型超时评测通过。
- [ ] 模型、Prompt、策略、数据集和运行 ID 可追溯。
- [ ] 脱敏和数据出境检查通过。

### G5/G6 性能与稳定性

- [ ] 50 个独立授权客户端的真实 DeepSeek SSE 压测完成。
- [ ] AI 首输出小于 3 秒，P99 小于 5 秒。
- [ ] 断线、取消、429、模型超时和依赖故障行为正确。
- [ ] 连续五日记录请求、错误、延迟、依赖、重启和审计完整性。
- [ ] 可用性达到 99.5%。

### G7/G8 灰度与签署

- [ ] 按“人工消息→发券→地址→营销→低风险自动回复”逐项灰度。
- [ ] 每项有独立开关、白名单、审计、停止条件和回滚证据。
- [ ] 测试工程师无未关闭 P0/P1/P2 生产阻断项。
- [ ] 架构师完成技术验收。
- [ ] 产品负责人批准真实店铺灰度范围和自动化策略。
