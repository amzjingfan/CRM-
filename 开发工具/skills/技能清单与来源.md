## 统一使用规则

1. 使用 Skill 前先阅读该目录下的 `SKILL.md`。
2. Skill 只提供方法和约束，具体实现必须结合本项目 PRD、接口文档和架构决策。
3. 不得将 Skill 中的示例配置、密钥、第三方项目路径直接复制到生产环境。
4. 与本项目现有 `AGENTS.md` 冲突时，以项目内规范和架构师已确认的决策为准。
5. Skill 更新时重新下载对应来源，并在本文件记录日期和变更原因。
