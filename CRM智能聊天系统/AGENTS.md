# CRM 智能聊天系统代码 Agent 工作区

## 角色定位

本目录是项目正式产品代码的唯一归属地。所有 Agent 的正式实现都必须写入这里。

## 代码范围

- 前端应用和页面组件。
- Java/Python 后端服务和业务接口。
- AI Agent、Prompt、RAG、工具调用和模型适配实现。
- 数据库迁移、测试代码、Docker、部署、监控和日志配置。

## 代码归属

- AI 功能：AI Agent 开发工程师负责。
- 前后端业务：全栈开发工程师负责。
- 架构边界、核心选型和跨模块变更：架构师评审。
- 测试代码可以由开发 Agent 编写，测试结论由测试工程师确认。

## 开发规则

- **每次实施前必须先读取上级目录的 `共享记忆文档/`，确认当前项目需求、接口、架构决策和验收标准。** 未完成需求确认前，不得修改代码。
- 开发前阅读 `共享记忆文档/` 中最新需求、接口和架构决策。
- **每次编写或修改代码前必须读取 `共享记忆文档/代码编写手册.md`。** 所有代码必须遵守命名、分层、类型、异常、安全、测试和详细中文注释规范。
- 遵循对应角色目录中的 `AGENTS.md` 和 `开发工具/skills/` 中适用 Skill。
- 不在代码中提交密钥、个人信息、临时调试代码或未说明的第三方依赖。
- 每次变更都要说明修改文件、影响模块、验证方式、验证结果和已知风险。

## 完成标准

代码可运行、接口和页面符合契约、测试通过、无明显安全问题，并完成必要的文档和交接记录。

主责 Agent 完成代码实施后，必须在上级目录的 `共享记忆文档/实施记录/` 创建实施记录，文件名和内容遵守 `共享记忆文档/实施记录文档规范.md`。
