# 产品工程约束

本目录是正式产品代码的唯一归属地，包含前端、后端、AI/RAG、数据库迁移、测试、Docker、部署和运行配置。

## 开始前

- 遵守根 `AGENTS.md`，修改代码前阅读 `docs/development.md`。
- 涉及公开契约时阅读 `docs/api.md`；涉及组件、数据或隔离时阅读 `docs/architecture.md`；涉及模型、RAG、Prompt 或工具时阅读 `docs/ai.md`。
- 涉及部署和发布时阅读 `docs/deployment.md` 与 `docs/release-gates.md`。

## 实现要求

- 保持路由、服务、适配器、数据访问和后台任务边界清晰；数据库迁移可逆且按顺序执行。
- 所有业务访问绑定店铺范围，写操作按风险执行权限、CSRF、幂等、状态机和审计。
- Agent 只能调用白名单工具，不能直接访问平台 SDK 或业务数据库；模型不是业务事实来源。
- 真实平台、模型和高风险功能默认关闭，禁止通过代码、测试替身或配置默认值绕过失败关闭。
- 新增依赖、配置、接口、迁移或安全边界时同步当前文档和必要测试。

## 完成标准

实现满足当前契约，通过与风险相称的测试和静态检查，不泄露敏感数据，并在交付说明中列出修改、验证、未运行项和遗留风险。
