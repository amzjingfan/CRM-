# 客服人员使用指南（TikTok 人工辅助 v0.1）

> 适用对象：已获分配店铺权限的客服坐席。本文按当前本地产品实现编写；实际可用入口取决于账号权限、店铺授权、发送模式和环境部署。当前发布决策仍是 **staging 已授权单店人工辅助，production No-Go**。如界面与本文不同，请先核对当前部署版本，不要据本文尝试向真实买家重复发送。

## 上岗前确认

1. 使用管理员提供的管理端地址，输入**登录账号或邮箱**和密码，点击「登录管理端」。不要共用账号。
2. 进入「客服工作台」，确认自己能看到正确的 TikTok 店铺和会话。看不到店铺或提示无权限时，联系管理员检查店铺授权和账号权限。
3. 发送前查看会话的发送状态：「真实 TikTok 发送」表示确认后会触达真实买家；「模拟发送」只做模拟；「发送已关闭」不能外发。不要把模拟结果当成买家已收到。

## 一次完整接待

### 1. 找到并打开会话

- 在左侧按「全部」「未读」「我的」「星标」「已关闭」筛选。会话卡上的数字是该会话未读数；列表向下滚动可继续加载。
- 用平台、店铺筛选缩小范围。搜索框可查**买家昵称、订单号、物流号、商品**；多个词用逗号、分号或换行分隔，任一词命中即可显示。也可先选定搜索范围。
- 点击会话后核对买家、店铺和历史消息。打开时会定位到最新消息；翻看旧消息时，可使用「到最新」返回底部。不要仅凭相似昵称确认买家身份。

### 2. 核对业务事实

- 打开右侧「客户与快捷操作」，查看当前会话对应的订单、商品、优惠券和物流信息。只以页面实际返回的**当前店铺、当前买家**数据为准；字段为空或显示「状态待更新」时，不自行推断付款、配送位置、退款结果或优惠资格。
- 订单卡可打开「详情」核对订单号、商品规格、卖家 SKU、付款和收件信息。平台掩码按原样显示；「收据」是内部核对摘要，并非平台发票。页面没有开放退款执行。
- 物流状态旁可展开轨迹。若有多个包裹，先选对包裹再复制物流号、翻译节点或制作物流卡片。增强轨迹不可用时，以现有通用轨迹为准；没有节点就说明暂未查到，不要编造物流进度。
- 商品、优惠券或物流数据加载失败时，使用页面提供的重试入口；仍失败则到官方后台核对并按团队流程升级，不用旧缓存或 AI 建议代替平台事实。

### 3. 准备回复

以下方式都只产生待审阅内容：

| 方式 | 怎么用 | 发送前检查 |
|---|---|---|
| 手动输入 | 在「回复内容」输入；`Enter` 进入发送审阅，`Shift+Enter` 换行。 | 收件人、订单信息、承诺与敏感信息。普通文本最多 2000 字。 |
| AI 建议 | 主动点击生成或刷新建议；建议会填入可编辑草稿，并替换当前草稿。 | 逐句核对知识、订单、政策和语气；不合适就修改或不用。AI 不会自行向买家发送。 |
| 快捷回复 | 点击「快捷回复」或在输入框用 `/快捷键` 选择；选中后填入草稿或进入审阅。 | 检查变量和适用店铺；同名快捷键优先个人话术，再选团队话术。 |
| 翻译 | 选目标语言，先点「翻译」看译文预览，或选「翻译后发送」进入准确内容审阅。 | 核对语言、数字、地址、商品名和政策用语；改动原草稿后重新翻译。 |
| 物流卡片 | 从物流轨迹选择包裹并点「发送物流卡片」，先在编辑栏看到卡片草稿。 | 核对包裹、物流号、轨迹和收件人；二次确认后才发送。 |

快捷回复的管理入口位于「智能营销 → 基础接待 → 快捷回复」。有权限时可按授权店铺管理个人或团队分组、快捷键、标签和文本段；停用的分组或话术不会出现在工作台。站点目前仅作话术标签，不会自动按买家站点筛选。快捷回复管理页的图片、视频模板暂不可用。

### 4. 审阅并确认发送

1. 在发送栏选择「直接发送」或「翻译后发送」，点击主按钮进入「审阅外发消息」。
2. 在弹窗中核对**收件人、平台、目标语言及「即将发送的准确内容」**。有译文时同时核对原始草稿。若显示真实发送提示，确认操作会向真实 TikTok 买家发出并留下审计记录。
3. 需要改字时点「返回修改」；内容正确后点「确认并发送」。物流卡片同样须在独立弹窗点「确认发送卡片」。
4. 查看结果提示及会话消息状态。只有明确显示已发送，才能告知买家或同事发送完成。

在允许真实 TikTok 人工发送的会话，编辑栏还可选择图片或视频：图片支持 JPG/PNG/GIF/WebP 且不超过 10 MiB；视频支持 MP4/MOV/WebM 且大小为 10–100 MiB。选文件后先核对预览和收件人，再点「确认发送」；取消不会上传或外发。视频历史消息显示发送状态，不保证可在工作台回放。

## 会话整理与交接

- **星标**：点击会话顶部星形按钮，或右键会话卡选择「星标」。这是 CRM 内部的差评风险标记，不会通知买家。
- **转交**：点击「转交会话」或右键会话卡选择「转交」，从有当前店铺权限的坐席中选择目标并确认。转交前在团队约定渠道交代未解决事项；不要把跨店铺资料复制给无权限人员。
- **关闭与重新打开**：点击「关闭会话」后在确认弹窗点「确认关闭」，会话移至「已关闭」；需要继续处理时点「重新打开」。这只改变 CRM 工作流，不代表 TikTok Seller Center 会话同步关闭。已关闭会话不能发送；新买家消息可能使其重新活跃。
- **买家阶段**：可在会话顶部查看售前、售中、售后或待判断；确有依据时手动选择，也可「恢复自动判断」。自动判断依赖已核验订单数据，查询失败时不要据此作业务承诺。

## 异常情况速查

| 页面情况 | 坐席处理 |
|---|---|
| 「发送已关闭」或按钮不可用 | 停止外发，核对当前店铺、会话状态和账号权限；由管理员处理配置。 |
| 显示「发送结果未知」或 `unknown` | **不要再次点击发送，也不要改写内容重发。**先在 TikTok 官方消息记录核对是否送达，再按团队流程申请对账处理。文本、媒体、物流卡片均如此。 |
| 显示平台拒绝发送 | 记录页面错误与时间，核对原因；不要假定买家已收到。确认原因后再按团队流程处理。 |
| AI 建议失败、没有引用或内容与订单冲突 | 使用已核验事实人工回复，必要时升级；不要把模型猜测写成平台事实。 |
| 订单、物流、商品或优惠信息为空/加载失败 | 使用页面重试或官方后台核对；不凭空补全缺失字段。 |
| 页面长时间加载或出现 502/504 | 记录时间、店铺与页面位置并报告管理员；发送中断时先按「结果未知」流程对账。 |

## 使用边界

- 本期是**人工辅助**：AI 建议、翻译、快捷回复、欢迎语和超时回复配置都不会自动向买家发送。欢迎语与超时回复即使显示「启用」，也只是保存本地策略。
- 不在客服工作台执行退款、发券、改地址、主动营销或公开自动回复；页面中的内部预览和配置不代表平台动作已经发生。
- 只处理自己获授权的店铺和会话。不要在聊天、截图、导出材料中泄露账号密码、Token、客户完整联系方式或不必要的订单信息。
