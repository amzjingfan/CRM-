**Goal:** 调试页真正流式输出，提交立即清空输入框；从 TikTok US 订单物流 Agent 创建持久模板并应用 XBM，完成真实测试后只清理测试数据，保留模板及 XBM 订单物流 Agent。

## 约束与验收

- AC-01 提交后立即显示用户问题并清空输入框，等待期间可编辑下一条；失败不覆盖新输入、不自动重发。
- AC-02 真实模型分片在最终结果之前到达；最终结果替换草稿，失败或断线移除未复核草稿；工具、引用和 trace 保留。
- AC-03 切换店铺/Agent、清空和离页均中止旧请求，旧结果不得回填；租约释放和取消运行有持久记录。
- AC-04 模板模型、七段提示词、工具与回复配置匹配 US 源；XBM 文件独立映射，未绑定不回退 FAQ。
- AC-05 XBM 当前 Agent 与店铺路由、中文英文、工具与知识检索及失败情形有真实证据；不发送真实消息。
- AC-06 问题先汇总，完成本地验证和审查后统一 PR/部署；保留翻译 overlay、安全开关和其他会话成果。
- AC-07 仅清理明确属于本轮的合成文件/会话等测试数据；模板和 XBM 订单物流 Agent 保留，历史审计保留。
