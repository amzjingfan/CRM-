## 页面设计

1. **店铺 Agent**：移除基础设置中的大块模板来源面板、逐字段来源及技术编号。模板更新与解除关联归入“更多”操作；后台关联和已发布历史继续保留。回复参数分组改名“回复偏好”，说明客户语言与坐席语言的区别。
2. **模板编辑**：删除可选的“模板职责说明”表单项；保留用于模型路由的“Agent 职责描述”。以“基础信息 / 模型与提示词 / 工具与知识”分组或标签呈现。名称和当前状态清晰置顶；保存、发布、应用为主要操作。编码、历史版本、归档等低频操作收进高级设置或菜单，保留已有值与接口兼容。
3. **批量应用**：分为“选择店铺 → 配置与差异 → 确认应用”。按用户最新批注，店铺通过可搜索多选下拉框选择，版本与选择控件紧凑同排；默认收起，不再长驻展示店铺列表。展开后可搜索、分页、勾选及移除已有选择；跨搜索和跨页保留选择，支持键盘、Escape 和外部点击收起。默认仅显示店铺、目标 Agent、变化摘要、冲突和必要知识绑定；逐字段完整值折叠查看。没有变化的字段不占主页面；冲突仍需明确处理，不能隐藏阻断原因。保留已有 Agent 选择、发布选择和冻结预览确认。
4. **批量任务**：顶部使用任务下拉选择器，支持分页；选中任务即同步 URL，深链接和前进后退继续有效。主区显示状态、成功/失败/待处理计数及店铺结果。只显示当前可用动作，技术编号和重试细节折叠。
5. 统一留白、字号、按钮层级、表单标签和错误反馈；宽屏双栏、小屏单栏，无页面横向溢出或多层固定高度滚动。按用户补充批注，版本、搜索、筛选及分页集中到紧凑工具栏，短输入不无限拉伸，批量应用的版本和店铺搜索同排；小屏自动换行，长提示词保留编辑宽度。

## 回复偏好生效规则

- **语气**：友好、专业、简洁、共情四项进入已发布配置，并作用于专职 Agent 和最终汇总的表达要求；不改写工具事实。
- **客户回复语言**：明确中文/英文时按配置；自动时由模型依据本轮买家问题判断。历史消息、工具文本和内部任务语言不能覆盖本轮买家语种。
- **坐席工作语言**：只决定内部说明/翻译视图的工作语言，不覆盖面向买家的正文；界面明确这一用途。没有对应内部说明的场景不额外生成无用正文。
- 七段系统提示词保留；对显式语气和语言参数，发布编译器生成统一的表达约束，避免 Worker 与汇总各自忽略配置。
- 参数必须随发布版本冻结；草稿修改不影响当前运行。必要时增加可回滚的发布快照字段，旧版本按兼容规则读取，不从可编辑草稿偷读。模板应用与差异预览同步处理实际支持的字段，不能丢失本店配置。
