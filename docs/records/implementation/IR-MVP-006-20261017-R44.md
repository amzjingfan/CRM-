# G5 手动窗口恢复原受控会话

用户确认 G5 完成后必须恢复窗口前的六个不可变摘要及原 G3 单会话人工发送能力。手动入口新增 `RestoreManualSend`，并将三个恢复模式都绑定到 `DeployG5` 前保存在仓库外私有目录的运行态快照。快照包含六摘要、唯一允许会话、Webhook 只读和工作台翻译状态；恢复参数及模式与快照不符时停止，恢复使用原三摘要而非候选摘要。

生产门禁与紧急回滚使用同一 Rootless 主机独占锁；G5 部署在锁内复核预窗口状态，恢复在锁内复核当前容器仅属于本次候选或原摘要，backend 仅处于 G5 或快照原模式。唯一已停止容器可作为部分部署状态对账；容器缺失、重复、窗口外摘要或其它模式失败关闭。恢复后复用现有运行态、健康、固定出口门禁；不会扩大 TikTok 写入到第二个会话。

变更限于手动脚本、确定性测试和部署说明。本轮未切换 staging、调用 DeepSeek、发送消息、签发凭证、发布镜像或使用 GitHub Actions。现有 R43 隔离 FAQ 已就绪；现场单会话和 50 并发仍独立实施。
