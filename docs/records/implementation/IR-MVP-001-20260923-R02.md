- `TIKTOK_WEBHOOK_SECRET` 在本项目只用于本地 Mock `X-TTS-Signature`，staging 留空。真实 TikTok Webhook 由 `TIKTOK_APP_SECRET` 按现有代码验签；原 R01 把 Mock 字段列为外部待准备项的表述已在部署说明中纠正。
- 一次性工具首次从 root 不可访问的工作目录运行 Rootless Compose，在任何容器变更前因权限错误失败。工具自身没有报告自动回滚成功；独立复核活动 env 与旧恢复副本字节相同、应用容器未变且健康、三个公网端点 200。将 Rootless Compose 工作目录修正后，复用同一恢复副本再次执行并通过。不得把首次失败写成自动回滚通过。
