# 本次实施与原因

R30 现场报告的终态为 34/36：页面否定说明缺必需表达，多语言政策首稿缺平台审核步骤，受控修复由模型转人工。报告只保存低敏诊断，没有草稿原文，因此不能断言模型实际措辞。R31 只针对这两种可见结果收紧合成评测指令：有证据的页面否定说明要明确写出“未显示/没有显示”完成状态；政策证据同时给出申请时限和平台审核时，修复稿保留两者及 `refund_policy` 声明，同时禁止推断个案审核结果。Prompt 版本升为 `real-model-eval-v1.2.11`。

冻结数据、判分、DLP、政策验证器、每条调用上限、安全开关、真实消息发送及 production 均未修改。新指令没有引入冻结评分标签或样本答案。对应请求契约测试和 `docs/architecture/AI.md` 已同步。

# 交接与边界

本地确定性测试只能验证指令和现有安全路径，不能证明 DeepSeek 会按新指令给出合格输出。本轮没有发布镜像、部署 staging、运行付费模型或发送外部消息；G4 保持 `PARTIAL`。后续若进行现场复测，需分别遵守私有镜像、staging 部署与付费模型调用的精确授权边界，并核对两条失败样本及全量安全指标。
