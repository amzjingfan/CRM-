# 双语工作台部署前前端依赖修复

从已合入的 [R01 UI 候选](IR-MVP-CONV-UI-001-20261016-R01.md) 继续。精确 main 源码的前端镜像在 `npm ci` 报告运行时 Next.js `16.3.4` 为 critical，`sharp` 和 `source-map-js` 为 high。官方公告指出该 Next.js 问题需要应用使用 Node.js `next/og ImageResponse` 并将攻击者控制的值写入 SVG；当前前端源码未使用该接口。为免 staging 新镜像继续携带已知受影响版本，本修复分支将 Next.js 和匹配的 ESLint 配置更新到同系列 `16.3.8`，锁文件内 `sharp` 到 `0.35.5`、`source-map-js` 到 `1.2.2`，并同步精确版本契约测试。没有改动翻译、TikTok 读取或平台消息发送逻辑。

本次只构成源代码与本地构建候选。旧 `main=3496738` 的两张本地镜像尚未发布；发布将使用本修复合并后的精确 main 再构建。staging 与 production 运行态未因此改变。
