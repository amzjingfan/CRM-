成功门禁证据为 [`crm-staging-tiktok-egress-20260923.json`](../../../release/evidence/staging/crm-staging-tiktok-egress-20260923.json)：观测出口精确为 `38.55.145.52`，迁移头已应用，三个公网健康端点为 200。只停止 staging 出口 helper 后，同一 backend 容器验证器返回非零，backend/jobs 的已建立直连 443 连接快照均为 0；helper 恢复健康后再次观测相同出口。经代理对两个 TikTok 官方端点执行无凭据 TLS 请求并收到 HTTP 响应；未执行真实店铺授权、消息或客户数据调用。
