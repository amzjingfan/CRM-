# R63 固定转人工原因诊断

[R62 现场](../../reports/tests/TR-MVP-006-20261018-R62.md)的合成 SSE 正常结束却无安全 `delta`；Agent 转人工且最终置信度为零，原低敏摘要不能分辨哪个现有决策输入触发。R57 已包含用户确认的安全复核 Prompt 必需字段和 Schema 路径白名单，本轮不重复修改 Prompt。

在现有 `_confidence_evaluated` 决策节点按固定优先级生成一个 `decision_reason` 枚举，区分意图未确定、知识缺失、草稿要求人工、安全复核布尔项、复核置信度和检索/草稿置信度等现有分支。持久化端口对该值再次按白名单校验，未知输入只写 `unknown`；不保存模型正文、Prompt、字段值、原始异常或请求 ID。`action`、置信度计算、严格 Schema、DLP、安全阈值、模型调用上限及 TikTok 发送开关均未改变。架构事实同步到 [`AI.md`](../../architecture/AI.md)。
