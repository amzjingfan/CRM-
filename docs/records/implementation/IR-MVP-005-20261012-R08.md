# 实施目标与范围

用户批准仅修复 G4 合成评测 Prompt 对否定说明、条件政策和西语英译的语义约束，并为失败报告增加缺失必需内容的冻结组序号。镜像、staging 部署和再次付费模型调用分别保留独立授权边界。

# 实际变更及原因

已获精确授权的 `v1.2.3` 后端从 main `5c1b97f21f740fd5e6cc47070cb374c33d48f3bc` 发布单个不可变镜像，经六角色预取、validate、staging deploy、三项健康和运行摘要核对。`prepare` 零 Provider 调用；一次 `live` 对 34 条合成样本调用 DeepSeek、2 条本地故障注入，得 33/36，三条逐项失败。该现场事实保存在本次入库的低敏原始 artifact 与[部署汇总](../../../release/evidence/staging/crm-staging-g4-v123-rollout-20261012.json)。

先增加冻结请求和诊断测试并观察预期失败，随后把评测专用 Prompt 提升到 `real-model-eval-v1.2.4`：页面未显示不能推断真实退款结果；英文条件政策只说明平台批准是前置条件，不声称已批准；翻译保留“准备中”和“尚未发货”。诊断只输出缺失必需内容的冻结组零基序号（0～7），工作流嵌套白名单检查数组长度、整数类型与范围。代码和 AI 契约固定在 `final_sha`。

# 关键决定与偏差

`v1.2.3` 的售后与引用两条旧失败在真实复测中已过，但否定、英文条件和西语英译三条出现新失败；33/36 的数值门槛通过不关闭 G4。本次未改冻结数据、判分函数、禁用词匹配、85% 阈值或真实发送开关。新增索引只用于低敏定位，不豁免失败。

# 数据、配置、接口、迁移或 Prompt 影响

仅 G4 合成评测专用 Prompt 版本与诊断报告字段/工作流白名单变化。公共 API、数据库、真实 TikTok 写入、自动回复和 production 配置不变。旧 `v1.2.3` 报告不回填新诊断字段。

# 验证交接

R08 TR 记录红绿测试、完整回归、静态检查、工作流解析与真实 `v1.2.3` 证据。R08 RR 审查严格判分、原文不落盘和授权边界。`v1.2.4` 合入后须分别获批镜像、staging 部署和真实模型复测，并逐项复核全部 36 条。
