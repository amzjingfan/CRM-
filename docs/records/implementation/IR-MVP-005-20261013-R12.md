# 目标与范围

用户批准按既有 G4 评测流程做有界 Prompt `v1.2.6` 修复：条件政策只说明平台批准这一前置规则，购物车草稿只表达允许的提醒，不复述缺席的促销或库存紧迫话术。仅修改合成评测 Prompt、版本、契约测试和对应 AI 文档；镜像发布、staging 部署和真实 DeepSeek 复测各自另行授权。

# 实际实施

`v1.2.5` [获批 live 报告](../../../release/evidence/ai/crm-staging-g4-v125-live-38330782377.json)为 34/36：`condition-open-002` 与 `abandoned-open-001` 均命中禁用内容，`negation-open-002` 已恢复。候选在同一通用评测系统 Prompt 中增加输出前自检：删除对具体申请获批状态的肯定或否定句，只保留一般现在时前置规则；购物车营销仅保留查看或结算提醒，删去对缺席促销或库存紧迫话术的复述，包括否定句。没有按样本 ID 分支，也没有把冻结禁用词原文写进 Prompt。

先新增覆盖两类冻结输入共享系统 Prompt 的契约测试，观察缺少新约束的预期红灯；再改 Prompt 与版本，定向测试转绿。代码与 AI 当前文档在 subject 提交 `final_sha` 中。没有改产品运行路径、公共 API、数据模型或迁移。

# 决定、风险与边界

冻结 36 条独立数据、严格禁用词判分、85% 门槛、结构化声明约束、DLP 和 TikTok 安全开关保持不变。通用 Prompt 可能仍被模型忽略，也可能影响其他合法样本；本地契约不能证明真实 Provider 输出。当前 staging 继续运行 `v1.2.5` 后端，G4 仍 `PARTIAL`，production No-Go。
