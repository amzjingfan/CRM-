# 原因与范围

R08 第二次获批的单令牌只读诊断 #38862950177 显示令牌有效、运行签名密钥和算法匹配，但后端 `/v1/auth/me` 返回 HTTP 500 / 应用错误码 50001。用户批准一次性读取该请求附近固定 15 秒的后端结构化日志，且仅输出白名单异常类型和计数，不再发送认证请求。

# 实施

- staging Runner 新增 `diagnose_auth_logs` 模式，仍锁定精确 main、运行后端摘要和数据库指纹；只对 2026-10-16 06:45:05–06:45:20 UTC 调用一次 `docker logs`。
- 日志仅传入无网络、无凭证、只读的一次性容器。分类器再次核对结构化 `timestamp` 与 `internal_error` 事件；异常类型按白名单计数，其他统一为 `other`。原始日志、trace ID、身份、Token、异常文本及响应正文不输出。
- 既有凭证池和 `provision` 均不读取或修改；SSE、Provider 与 production 不触及。

# 下一步

经 PR/CI 合入 main 后仅执行一次获批的固定窗日志检查。若没有匹配事件或结果仍不唯一，如实记录，不以猜测修复账号或放行 G5。
