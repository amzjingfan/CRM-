# 本轮实施

PR #102 已合入 main；staging Runner 的只读诊断在已部署 backend 上查询到订阅数 0，证据见[订阅读取汇总](../../../release/evidence/staging/crm-staging-g2-subscription-read-20261009.json)。因此本轮准备一次性订阅工具，仅在单独精确授权后可执行。工具固定主题 `NEW_MESSAGE` 与 staging HTTPS 回调地址，沿用已验证的跨境店铺 `shop_cipher`、当前加密 Token、固定出口 HTTP 客户端和 202309+ 请求签名。官方本地 OAS 只列出 `PUT /event/202309/webhooks`；在线 docv2 页面未返回完整契约，尚未证实是否有更新版本。

执行前 GET 必须发现空订阅；若精确目标已存在则无写入返回，若有其他订阅则失败关闭。最多发出一次 PUT，之后 GET 对账；网络错误或读后状态不一致时记为 `unknown` 且不自动重试。工作流从 main 获取并校验脚本 Git blob，核对 staging 后端不可变摘要，输出不含 URL、Token、shop_cipher 和平台请求 ID 的证据。不发布新镜像、不修改 production。

# 状态与后续

本轮只提交代码、测试与文档；**尚未触发外部订阅写入**。G2 真实投递、签名、店铺绑定、重试、乱序、审计及默认模式实际切回仍未验，任务保持 `DOING`。外部 PUT 执行前需用户单独批准精确主题、地址和目标。
