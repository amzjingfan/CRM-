# R93 独立 SSE 断连现场探针

新增一次性 `probe_sse_disconnect.py`：只访问 staging 后端容器网络的 loopback 端口，先以隔离 CRM 凭证读取 `/auth/me`，随后请求合成会话 SSE，在 `accepted` 到达后关闭连接，不读取模型正文。客户端正式输出仅包含固定类别、HTTP 状态及接受耗时；用户 ID 与 trace ID 独占保存于仓库外私有目录，供现场同一 trace 日志和 Redis 租约核对，不进入仓库证据。

目标与输出路径均限制在固定值；输出文件使用独占创建和权限 600，失败类别不包含响应正文、Token 或原始异常。同步更新当前部署与测试策略，明确客户端关闭、服务端断连且未完成、租约释放及 G3 恢复必须独立核对。本次不修改 SSE 服务器行为、模型 Prompt、阈值、DLP、店铺隔离或 TikTok 写入边界。

限制：确定性测试只能证明探针会关闭测试流，不证明 staging 服务端收到断连或释放租约。现场验收将在独立可恢复窗口记录低敏结果；此记录不关闭 G5。
