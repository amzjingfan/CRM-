# R77 本地检索容量与政策声明候选

[R76 现场](../../reports/tests/TR-MVP-006-20261018-R76.md)的 50 并发仅 45 条有安全输出，检索 P99 24731 ms；零 DeepSeek 分段探针显示本地 BGE 向量化与重排共用推理锁，唯一命中 FAQ 时重排仍被调用。另有一条独立复核在 `business_claims:claim_action_mismatch` 处严格失败。

本次仅对本地 BGE 的**脱敏查询向量**按事件循环、可信店铺、模型、维度和问题摘要短时复用，成功结果最多保留 3 秒及 128 项；同时到达的同键请求共用一次未完成调用。失败不缓存，最后一个等待者取消时取消未完成调用。复用请求不重复计入 Embedding Token 用量。每条请求仍用自身授权会话重新执行本店数据库检索与当前知识审批、版本和证据核对；没有缓存 FAQ 内容、候选或复核结论。

仅一个召回候选时跳过不能改变排序的 Cross-Encoder，仍执行原 Dense/词法分数阈值和上下文预算；多候选继续重排。独立审批 FAQ 复核 Prompt 升到 `faq-trusted-review-v1.0.1`，明确一般退款政策只能输出 `subject_type=refund_policy`、`action=explain_policy` 组合，注册 SHA-256 为 `3207bb2f3d06c5d4ad414e229a470e39c63cc3aba5bb4ebe072835b4b540788e`；工作流版本 `faq-agent-workflow-v1.8.4`。严格 Schema、业务声明复核、DLP、员工必审和 TikTok 写入开关均未改变。
