# 实际变更与原因

R41 的 34 次真实生成均在约 15 秒后 `LLM_TIMEOUT`；R42/R43 只证明无凭据请求路径在探针时刻可用。按用户确认的有界设计，[PR #201](https://github.com/CP11-gh/CRM/pull/201) 在既有 staging G4 工作流中加入独立 `canary` 模式，固定冻结样本 `order-open-001`。代码已 squash 合入 main `19e603f8578d31663393dc190ccb681f3817ef48`。

新模式先锁定 main SHA、运行后端不可变摘要、独立冻结集哈希和安全开关；沿用现有结构化请求及 DeepSeek Provider，仅发起一次请求，禁用 SDK 重试和修复调用，SDK 超时 15 秒、外层截止 20 秒。输出仅保留固定阶段标志、耗时分档、稳定错误类别和 Token 用量，不写 Prompt、响应正文、请求 ID 或原始异常。`request_hook_seen` 仅代表 HTTP 客户端调用了请求钩子，不证明服务端收到字节。同步更新契约测试和部署说明；运行中服务与生产配置未改变。
