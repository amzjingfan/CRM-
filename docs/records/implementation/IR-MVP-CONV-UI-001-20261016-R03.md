# DeepSeek 翻译结构化输出契约修复

`14ec836` 已在 staging 部署，真实 TikTok 会话的买家左侧、卖家右侧和原文入口可见，发送仍关闭。但对一条真实客服文本执行两次按需翻译均失败，后端低敏日志为 `LLM_OUTPUT_INVALID`；同模型、同旧提示词的合成句探针返回 `type` 和 `translation`，缺少后端要求的字段。原提示词只要求“结构化对象”，而 DeepSeek JSON Output 仅保证 JSON 语法。

候选 `81f9963` 将翻译提示词版本升为 `customer-translation-v1.0.1`，明确要求四个字段、源/目标语言复制可信输入、无草稿时 `draft_translation=null`，更新 Prompt 注册摘要和架构文档。保留既有 Pydantic 校验、DLP、审计、限流和失败关闭；没有放开 TikTok 发送或生产翻译开关。部署及真实消息复测见后续现场记录。
