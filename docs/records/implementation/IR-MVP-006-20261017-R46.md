# R46 FAQ Prompt 与隔离夹具修复

针对 [R45](../../reports/tests/TR-MVP-006-20261017-R45.md) 单会话无安全 `delta` 的诊断线索，在现有 FAQ Prompt 构造器上对 `source_label` 调用已使用的脱敏函数；原隔离测试店 FAQ 的答案改为语义相同、无逗号的短句。DLP 判定器、阈值、知识审批、店铺隔离及 TikTok 发送开关未改。

新增 `ReconcileFaqV3` 一次性入口，只在原隔离店铺 50 条问题、唯一已审批且已向量化的版本 2 FAQ、连续五份仓库外凭证与运行镜像提交均匹配时，将该 FAQ 答案升至版本 3、标记待向量化并记低敏审计。原版本 2 切片在此时不再可检索；后续 `VectorizeG5` 只允许用现有本地 BGE 精确替换这一条 FAQ 的切片。只读 `ContentCheck` 识别版本 3 的待处理与就绪状态。确定性及真实 PostgreSQL 测试覆盖不符前提的失败关闭。

本记录仅对应已提交源码。未向 staging 写入 FAQ、运行 BGE、发布新镜像、切换服务、调用 DeepSeek 或执行 50 并发；G5 仍未通过。这些现场动作需分别核对当前主分支、运行摘要与精确授权。
