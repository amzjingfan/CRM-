# R90 首输出前指标写入低敏计时

[R89 现场](../../reports/tests/TR-MVP-006-20261018-R89.md)最慢两个客户端首 `delta` 约 3991/3982 ms，匹配服务端内部安全结果约 2809/2996 ms，认证约 396/384 ms；余量还包含原有首输出指标写入及 SSE 传输，无法单独归因。此候选只在 `SSE_LOAD_TEST_ENABLED=true` 且安全工作流成功后记录 `record_first_output_latency` 的真实等待：固定事件 `g5_chat_first_output_persist_timing`、校验后的追踪 UUID 和非负整数毫秒。不保存会话、身份、Token、正文、Prompt、模型输出或异常文本。

原指标写入仍先于首个 `delta`；DLP、店铺隔离、安全复核、审计、模型调用、发送开关与严格 3 秒/5 秒门槛均不变。普通 G3 模式不输出新事件。本轮只改源码、确定性测试和 [AI 契约](../../architecture/AI.md)，没有构建/发布新镜像、切换 staging、调用 DeepSeek、发送 TikTok 消息或使用 GitHub Actions。现场验证需要合并后用匹配镜像在可恢复窗口运行。
