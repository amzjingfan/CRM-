# R88 细分认证和上下文数据库耗时

[R87 现场](../../reports/tests/TR-MVP-006-20261018-R87.md)取得 50/50 安全输出，但首 `delta` P99 4121.54 ms，仍超严格 3000 ms。成功认证 P99 1322 ms，现有证据未区分数据库连接等待与用户/权限查询；Agent 上下文的店铺范围、会话和配置读取也尚未单独计时。PostgreSQL 活动采样器误用 R85 镜像断言，本轮没有事务峰值；这些资料不足以确认单一根因。

只在 G5 SSE 压测模式记录固定事件和整数毫秒：令牌解析、数据库连接获取、用户查询，以及店铺范围、会话/触发消息、Agent 配置读取。无效令牌先被拒绝，不额外获取数据库连接。日志保持经校验 trace UUID 和数值白名单，不记录用户、店铺、Token、SQL、Prompt、客户正文或模型回答。普通 G3 路径不产生新增事件；原店铺隔离、权限、CSRF、DLP、发送开关、模型调用、严格 3 秒/5 秒门槛均不变。

本轮只交付本地源码和测试；staging 已保持 R87 恢复的 G3 单店人工发送模式。匹配 main 的镜像、可恢复现场诊断、PostgreSQL 活动采样与独立断连仍是后续工作；不将本地检查当作 G5 通过。
