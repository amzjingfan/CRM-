# 实施目标与范围

用户批准在既有 G4 合成评测 Prompt 中有界修复两条英文语义失败。只提交本地代码与确定性测试；镜像发布、staging 部署和再次付费 DeepSeek 调用仍须各自单独授权。

# 实际变更及原因

已部署的 `v1.2.4` 一次真实评测为 34/36；`negation-open-002` 缺状态未确认的必需组 0，`condition-open-002` 命中未引用禁用短语。候选 `real-model-eval-v1.2.5` 在同一个合成评测系统 Prompt 内增加两类通用英文正向句式：否定状态标签只解释其未确认含义；条件政策用一般现在时表述平台批准前置规则，不追加具体申请审批现状。不是按冻结样本 ID 分支，也未把禁用短语放进 Prompt。

测试先行，扩展冻结请求契约覆盖第二条否定样本并新增两类句式断言，观察预期红灯后只调整 Prompt 与版本。源码 subject 为 `final_sha`。产品运行代码、公共接口和真实 TikTok 写入没有改动。

# 关键决定与偏差

保留冻结 36 条数据、严格禁用词判分、85% 数值门槛、结构化声明约束、低敏输出与安全开关。一般句式须由模型按证据调整动作和主体，不能扩展为具体申请事实。模型真实遵循性未知；本机绿灯不关闭 G4。

# 数据、配置、接口、迁移或 Prompt 影响

仅 G4 评测专用 Prompt 版本和内容变化；无数据库迁移、配置或公开 API 变化。当前 staging 继续运行 `v1.2.4` 不可变后端摘要；候选 `v1.2.5` 尚未发布或部署。
