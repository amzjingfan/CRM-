# 实施目标与范围

为 G5 的 50 客户端 SSE 现场测试增加零模型调用准备环节。用户已确认仅实现只读预检与确定性验证；真实并发、临时限流配置和 DeepSeek 费用另行处理。

# 实际变更及原因

- 在现有 `load_test_sse.py` 增加 `--prepare`。从仓库外凭证池逐项只读查询 CRM `/v1/auth/me` 和指定会话消息，核对 50 个不同授权用户及各自会话可读；输出仅为计数、固定失败类别和 `provider_calls=0`。
- 对非预期的成功响应结构、重复身份、会话权限、路径和已有报告实行失败关闭。通过 Git 元数据同时识别当前 checkout 与主仓库根；凭证及输出必须位于两者之外，输出文件采用独占创建。
- 扩充确定性测试，更新现场操作说明与测试策略。现有负载模式、发送开关、模型配置和服务部署均未修改。

# 关键决定与偏差

声明的单 IP 限流值只做输入合理性检查；预检不能证明服务器运行值、实际并发容量或模型质量。现场凭证池未取得，不把本地合成测试写成 50 账号现场通过。

# 数据、配置、接口、迁移或 Prompt 影响

无数据库迁移、公共 API、Prompt、运行配置或镜像变化。仓库不保存凭证、用户标识、消息正文或现场原始响应。
