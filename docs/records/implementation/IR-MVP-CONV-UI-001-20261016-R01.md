# TikTok 工作台双语消息

买家气泡改为左侧白色、卖家/客服气泡为右侧蓝色，机器人沿用出站侧、系统消息居中。原文保留；坐席点击单条“译成中文”后，在同一气泡内以虚线隔开显示 DeepSeek 中文辅助译文。新前端仅在详情接口明确返回 `translation_enabled=true` 时展示入口。

后端新增单条消息翻译接口。请求只带会话与消息 ID；服务端校验登录、`workspace.view`、CSRF、限流、授权店铺、会话和 TikTok 文本类型，再将消息交给现有 `TranslationService` 的 DLP/结构化输出链路。通用 LLM 和 TikTok 消息发送不因此启用。成功或失败只追加低敏审计，不保存译文或原文副本；翻译失败保留原文并允许重试。

新增默认关闭的 `WORKSPACE_MESSAGE_TRANSLATION_ENABLED`，仅允许非生产环境配置 DeepSeek 后开启。Rootless staging 专用覆盖层只打开 backend 翻译，手动门禁复核合并配置与运行容器，兼容 G2 只读模式，与 G5 SSE 模式互斥。没有数据库迁移，翻译按需调用、当前页面内不重复调用，刷新后不保留译文。用户已授权真实消息送现有 DeepSeek 翻译；实际 staging 调用、镜像发布与页面现场验收另见 TR 及后续证据。

候选从 `b2729336` 建立，功能提交 `492ca94`；其后无冲突合入并行的 G5 `main` 更新，最终受测树为 `93b8476`。production 未发布，真实平台消息写入保持关闭。
