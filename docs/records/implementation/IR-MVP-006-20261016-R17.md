# G5 staging 手动部署入口

用户决定不再使用 GitHub Actions，并批准 GitHub 凭据加 staging 手动部署设计。subject `de1e3a1` 在独立分支增加 `Invoke-StagingManualG5.ps1`，复用现有 Rootless 六摘要预取、部署验证、默认配置恢复与上一版回滚门禁；固定当前远端 main SHA、GHCR 不可变摘要及后端 OCI revision。支持干净 Git checkout 和 SHA-256 已核对的 `git archive`，后者另以内容比较确认所有解包文件。使用进程 GitHub 凭据只读访问私有仓库及 GHCR，临时 Docker 凭据放在私有运行目录，结束时注销。
