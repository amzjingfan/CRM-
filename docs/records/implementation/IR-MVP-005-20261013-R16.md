# 目标与范围

依据已确认的[设计](../../superpowers/specs/2026-10-13-g4-policy-draft-validation-repair-design.md)，仅在 G4 离线合成评测中对政策草稿引入可信证据校验和最多一次修复。正式回复工作流、公开接口、TikTok 发送与 production 均未改动。

# 实际变更

- 新的无副作用政策校验器识别中英文批准前置条件、审核步骤、无依据的个案获批措辞及引用不匹配；不读取冻结评分标签。
- 修复请求使用单次摘要授权和严格字段白名单；只包含合成消息、证据、目标语言、首轮草稿与通用原因码，DLP 拒绝凭据、PII、地址和额外答案字段。
- 评测器分别给首轮和终态使用原冻结评分器；最多 68 次 Provider 调用、120000 Token 配置上限。修复后重新检查完整结构、DLP、证据与政策安全；阻断时隐藏正文并清空声明。报告保存阶段性哈希、评分、低敏诊断、用量、延迟和调用数，不保存草稿原文。
- staging 工作流对 `policy-repair-v1` 低敏报告做字段白名单和 34～68 次调用上限检查，保留 `prepare` 零调用。AI、测试策略、发布门禁当前文档已同步。

# 决定、影响与交接

冻结 36 条数据、原评分函数、85% 阈值和安全开关均未改动。此 subject 只证明源码候选和本地验证，不构成真实模型质量通过。staging 仍运行 `v1.2.7`，G4 保持部分通过；后端私有镜像、staging 部署及新的最多 68 次付费模型评测各需精确授权。回滚源码可 revert 本 PR；无数据库迁移或运行配置切换。
