# 目标与实施

[R07 一次获批的只读诊断 #38861412442](https://github.com/CP11-gh/CRM/actions/runs/38861412442) 证实第一枚现有令牌的本地签名和有效期有效，签发密钥、算法与运行后端一致；一次 `/v1/auth/me` GET 被旧诊断器归为 `other`，不能区分 HTTP 4xx/5xx。用户明确批准细分固定状态和白名单 API 错误码，并在 PR/CI 后再次只读请求一次。

本次只修改诊断报告和工作流输出白名单：对常见 4xx/5xx 记录精确状态数字，对不超过 4096 字节的响应仅提取已定义的数字错误码；其余固定为 `unknown` 或 `other`。响应正文、Token、签名配置、身份和原始异常不输出。现有单令牌、最多一次 GET、禁用环境代理、精确运行摘要和 `provision` 守卫保持原状。
