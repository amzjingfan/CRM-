# 审查范围、依据与重点风险

审查本次 G4 评测专用 Prompt 候选、冻结样本请求契约、严格判分是否保持、真实评测与部署授权边界，以及新入库低敏证据。此审查只批准代码候选进入 PR，不批准 G4、production 或再次付费调用。

# 发现、级别、位置和证据

- 售后 `claim_mismatch_fields=[count]` 对应缺失/多余声明；新增规则明确有证据时输出一条 `refund_policy`，证据不足仍转人工并清空声明，与既有失败关闭一致。未修改九维声明评分函数。
- 引用失败的诊断显示禁用词在引号和禁止语境内，但这不构成安全豁免；新增规则要求正文改述，不修改 `FORBIDDEN_CONTENT_PRESENT` 子串判分、85% 门槛或冻结样本。原有诊断测试仍要求这类引用在出现原词时判失败。
- `REAL_MODEL_EVALUATION_PROMPT_VERSION` 升至 `v1.2.3`；仅评测专用系统指令变化。外部请求安全登记仍按固定系统指令与冻结载荷校验，客户正文、模型草稿和禁用词原文不进入新报告。入库 `live` JSON 与工作流低敏 artifact 摘要一致。
- 本地测试与静态检查通过；新 Prompt 的真实模型遵循性未知。发布/部署旧 Prompt 的现场结果不能充当新 Prompt 验收。镜像、部署与下一次 DeepSeek 请求的授权互不替代。

# 已验证与未验证内容

已验证候选请求含两项明确规则、原评分器和冻结数据未变、完整后端回归与本轮旧版本现场来源。未验证 `v1.2.3` 的真实 Provider 结果、G4 两条失败闭环、G5/G6 和 production。

# 结论和返修条件

批准把候选 Prompt 修复合入代码基线；MVP-005 保持 `DOING`，G4 保持部分通过。若后续真实复测出现未引用的确定性承诺、无证据声明、禁用词复述或 Provider/安全指标回退，停止签署并返修，不降低评分规则。
