# R83 受控窗口审查

两次均从受审 main 和同一不可变候选镜像出发，50 个隔离身份、唯一 ready FAQ、单会话安全输出和恢复门禁通过。两次 50 并发均 50/50 安全输出，但首 `delta` P99 6579.5/4878.8 ms，违反严格 `<3000 ms`；第一轮总耗时 P99 6583.1 ms，也违反 `<5000 ms`。不能以第二轮总耗时通过替代首输出失败，亦不能把两轮安全输出完整解释为 G5 通过。

新增分段证明本地向量等待不构成主要长尾；混合搜索墙钟和请求接入仍有延迟。同步 PostgreSQL 状态采样观察到负载时最高 45 条 `idle in transaction`，是长开事务的直接证据；尚无连接池签出等待的独立计时，因此修复仍须明确验证连接生命周期而非仅扩大池容量或降低安全门槛。两次均从窗口快照恢复原 G3；独立断连验收缺失。`APPROVE` 仅确认本次试验的证据与失败关闭，G5 和 production 仍为 No-Go。
