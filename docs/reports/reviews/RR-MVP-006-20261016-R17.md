# 代码与边界审查

手动入口在任何 Docker 改动前核对 Linux UID 1004、固定主机路径、GitHub 当前 main 完整 SHA、六个受审 GHCR 仓库摘要及 Rootless socket。归档模式同时核对传输 SHA 和全部解包文件，拒绝目录穿越、符号链接、额外文件和差异内容；clone 模式要求干净 checkout 与固定 origin。部署模式核对候选后端 OCI revision，复用既有六摘要预取和 G5 validate/deploy 门禁。恢复模式使用同一候选的默认配置，上一版回滚复用既有演练脚本。凭据不写入证据；Docker 登录隔离在私有临时目录并注销。

残余风险：PowerShell 门禁只在本地做语法与契约验证，未在 staging 运行；部署中途失败时只能根据实际容器状态选择恢复动作，不能盲目回滚。现场源包、镜像发布、SSH 身份与 `write:packages` 权限均未在本轮满足。审查批准代码进入 PR，不签署 G5 现场通过或 production 放行。
