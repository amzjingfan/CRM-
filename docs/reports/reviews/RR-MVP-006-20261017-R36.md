# R36 手动部署来源安全复核

审查范围为 subject 的手动入口和新增校验器。`Assert-StagingManualSourcePolicy.ps1` 仍要求 `CheckOnly`、`DeployG5` 锁 GitHub 当前 main；候选必须是指定 GHCR 仓库的不可变摘要。仅这两种新部署模式可接受较早的 OCI revision，且比较接口须证明祖先关系，两个具体 Git 对象须完整、唯一、类型与摘要均合法并完全相等。结果缺失、截断、分叉、后端目录或 Dockerfile 变化即拒绝；`RestoreDefault`、`RestoreReadAndTranslation`、`RollbackPrevious` 仍为精确 revision。Token 只在同一 PowerShell 进程传给 GitHub API，不写入证据或错误文本。
