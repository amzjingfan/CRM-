# R77 安全与运行审查

复核 subject diff 与确定性测试：缓存键从服务端可信店铺和已脱敏问题构成，只保存本地模型的向量结果，最多 3 秒/128 项；各请求继续独立执行有店铺条件、当前审批及版本条件的数据库检索。错误结果不缓存，取消后的无人等待调用被终止；非本地 Provider 不进入缓存。单候选省略的重排只改变排序成本，不删除原 Dense/词法阈值、知识元数据、政策声明、DLP 或员工必审门禁。复核 Prompt 明列合法政策动作，应用的严格 Schema 和本地声明校验仍是最终依据。未发现新外部自动发送路径。

残余风险：目前 50 条合成输入相同，复用向量主要改善此固定负载；不同问题的 50 路请求仍可能受本地 BGE 锁限制。短时缓存会使单条日志的向量用量只计到实际发起者，检索总耗时仍逐请求计。真实 DeepSeek 复核仍可能转人工或产生无效结构，模型耗时也可能超过严格阈值。PR 的自动 CI 作业受账户计费阻断，零步骤失败；审查依据是本地完整后端、静态检查和离线安全评测，不把该 CI 记为通过。`APPROVE` 仅表示该源码候选可进入可恢复 staging 验证，不表示 G5 或 production 通过。必须先通过单会话 `<3000/<5000 ms` 才能启动 50 并发；并发要求 50/50 安全输出、严格 P99、资源/断连及原 G3 模式恢复全部有现场证据。
