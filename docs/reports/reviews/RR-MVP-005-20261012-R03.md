# 发现、级别、位置和证据

- 现场失败明确为 `manifest.json` 读取权限，不涉及 Provider 调用。`docker cp` 后只对唯一运行目录内 `dataset.jsonl` 与 `manifest.json` 赋予读取位，未更改密钥文件、env、服务运行用户或宿主机权限。
