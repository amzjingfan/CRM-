# R75 安全和运行审查

复核源码与确定性测试：快路径只接收唯一命中的当前店铺当前人工审批通用政策 FAQ；模型只能复核，无法改写原答案。复核结果是强类型结构，应用再次检查唯一政策声明、空客户实例、一般时态和本次引用；原 ReplySafetyPolicy、DLP、语言、置信度及员工发送门禁仍执行。空声明、跨引用、过去时、要求个案判断、拒判和跨店命中均拒绝草稿。未使用或被取消的并行任务被等待回收，工具问题不进入该路径。没有发现可自动对外发送的新增路径。

残余风险：仅一个通用退货 FAQ 走快路径；真实模型可能拒判、超时、返回无效 Schema 或复核否决。推测性复核可能增加一次未消费的付费调用。安全通过不代表性能通过。现场若首安全输出不小于 3000 ms 或总耗时不小于 5000 ms，禁止启动 50 并发，必须恢复原 G3 模式；即使时延达标，也仍需 50 个不同账号的并发、资源与断连证据。此 `APPROVE` 仅针对本地候选的安全边界和后续受控试验，不代表 G5 或 production 放行。
