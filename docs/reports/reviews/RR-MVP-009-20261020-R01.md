# 审查范围、依据与重点风险

依据当前门禁、任务表、生产运行说明、历史镜像清单及本次只读现场结果审查 G8 决策。重点区分 G0～G6 的 staging 限定证据与生产运行证据，尤其 G6 用户风险接受仅适用于已授权单店 staging。

# 发现、级别和证据

**阻断 production Go**：生产拓扑尚未决定，当前主线对应的不可变镜像和生产切回目标没有本次证据；旧 G6 量化目标失败且公网间歇故障未定位；没有此次生产部署的精确授权。[决策材料](../../operations/G8-DECISION-20261020.md)列出解除条件。

**需单独处置的共享网关风险**：`sshd -T` 显示 root 与密码认证开启，存在外部失败登录尝试。未发现入侵或其导致 G6 故障的证据，也未在本次修改共享主机。若将该网关纳入生产，应先独立评审收紧与回退方案。

当前 staging 健康、固定出口和 G3 权限边界均为只读瞬时复核；不证明持续可用、跨店权限扩展、真实买家 AI 效果或生产安全。

# 结论和返修条件

**APPROVE 本轮 G8 的 production No-Go 决定。** 允许既有单店 staging 人工辅助在其限定风险接受范围内继续；production 不部署，不标记 `MVP_READY`。生产前按决策材料解除条件准备新证据及独立授权，再产生下一版 G8 决策。
