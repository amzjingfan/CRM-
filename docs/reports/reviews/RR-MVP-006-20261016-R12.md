# 范围与安全复核

复核确认脚本只接受 R05 固定文件名和与令牌签名一致的 50 个用户/会话；数据库还须逐项匹配原店铺标记、唯一 `workspace.view` 角色、原始邮箱、会话和 provision 审计，目标邮箱冲突或曾经修复均失败关闭。只读模式使用私有目录只读挂载；写入模式需工作流精确确认，创建新私有文件且不覆盖原文件。运行后端签名配置及数据库目标均独立核对，所有模型和 TikTok 写入开关关闭。报告只输出固定计数，不含令牌、原始异常或身份。

剩余风险：本地复现尚不是 staging 异常栈的直接证据；现场对账可能因实际批次与期望不符而停止。修复之后仍须重新验证 50 身份/会话，且运行限流 10 尚不足 50 并发。当前审查批准代码进入 CI，不代表授权执行 staging 写入或签署 G5。
